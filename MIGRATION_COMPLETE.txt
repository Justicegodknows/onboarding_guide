1️⃣  RUN DEPLOYMENT SCRIPT (from project root)
   $ ./deploy-to-dgx.sh
   
   This will:
   • Create directories on DGX
   • Copy backend code via rsync
   • Build Docker images
   • Start all services
   • Wait for services to be ready

2️⃣  VERIFY DEPLOYMENT
   $ ./verify-deployment.sh
   
   This will:
   • Check network connectivity
   • Validate all service ports
   • Test API endpoints
   • Report status

3️⃣  TEST FRONTEND
   • Navigate to: https://onboarding-guide-three.vercel.app/
   • Login with:
     - Email: admin@vaultmind.local
     - Password: admin123
   • Try uploading a document
   • Test chat functionality
